
## Getting Started

```bash
pnpm i
pnpm run dev
```

## Features
1. Plan your entire tour using an AI-powered trip planner.
2. Get a detailed, day-wise itinerary along with real-time weather updates.
3. Receive personalized recommendations for hotels, restaurants, and places to stay.
4. Discover the best attractions and must-visit spots based on your interests.
5. Download your complete trip plan as a PDF with one click.
